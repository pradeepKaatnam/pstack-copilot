=============================

SKILL.md files and every automation reference, template, and guide chapter.

HOST LIMITS

CLI: native agent/skill discovery and tools depend on installed CLI version and
installation. Available session history can be used, but private Cursor caches
must not be mined. No Cursor loop/Projects runtime is installed.

Native CLI delegation and background execution DO exist: the native task tool,
/subagents, /tasks, Ctrl+X b, and list_agents/read_agent/write_agent are distinct
from Cursor's Task signature and is_background frontmatter. This port chooses
safe inherited-model/sequential behavior where host capabilities are uncertain;
it does not declare those native features unsupported. CLI models/modelPolicy/
reasoningEffort agent controls and /model are also available, but no model names
or automatic role routing are invented here. CLI subagent model/effort settings
belong to ~/.copilot/settings.json under subagents.agents.<id>.model and
effortLevel, not obsolete internal ~/.copilot/config.json keys. MCP integrations
are native capabilities but are not supplied or authorized by this pack.

VS Code: custom-agent selection, skill discovery, extension version and configured
tools govern capabilities. Do not assume CLI history, delegation, model override,
or background continuation is available.

Cloud: repository/task configuration, credentials, network policy and branch
protection constrain execution. A cloud task is not a portable Cursor Project
coordinator or a guarantee of nested cloud workers, video, or permission to merge.
Cloud plugin configuration is documented through .github/copilot/settings.json
enabledPlugins and extraKnownMarketplaces; lack of integration testing here is
not a claim that cloud plugins are unsupported. The parent owns that setup.
